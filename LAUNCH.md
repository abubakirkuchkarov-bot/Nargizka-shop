# Запуск Nargizka Shop — инструкция

Ветка `turso-launch`, Pull Request #1. В `main` ничего не слито, рабочая база Turso не тронута.

## Что готово

**Хранение и надёжность**
- Все данные в Turso: товары, остатки, заказы, финансы, подписчики, настройки, пароль, настройки уведомлений. Фото тоже в Turso, отдаются через CDN.
- Каждая запись — транзакция `BEGIN IMMEDIATE`: два одновременных заказа не продадут одну вещь, ответ «сохранено» приходит только после записи.
- Ничего не стирается бесследно: удалённые товары/заказы/операции → `deleted_rows`; перед импортом — снимок в `backups`; журнал склада только дополняется.

**Товары и склад** (без QR и штрихкодов, всё вручную)
- Карточка товара: несколько фото, название, описание, категория, **бренд**, **закупочная цена** (видна только в админке), цена продажи, скидка, цвета, **остаток по каждому сочетанию цвет × размер**, скрытие с витрины.
- **Поступление** (несколько цветов/размеров сразу, закупочная цена, оплата поставщику автоматически в расходы), **списание** и **пересчёт** — с обязательной причиной.
- **Журнал склада**: каждое изменение остатка — кто/что/почему/сколько стало; правка остатка в карточке тоже требует причину.
- Поиск по названию, артикулу, бренду; фильтры; массовая смена цены и скидки, показ/скрытие.

**Заказы**
- Витрина проверяет наличие именно выбранного цвета и размера; недоступные размеры гаснут.
- Статусы: Новый → Подтверждён → Отправлен → Доставлен, а также Отменён и **Возврат**. Склад списывается при оформлении и возвращается при отмене/возврате **строго один раз** (флаг `stockOut`).
- **Оплата** отдельно от статуса: «Отметить оплату» / «Снять оплату». Отмена или возврат оплаченного заказа отмечает деньги возвращёнными.
- **Заказ вручную**: продажа в магазине (сразу оплачена и доставлена) или заказ по телефону (несколько товаров, скидка, доставка, статус, оплата).
- Удаление заказа (для ошибок и тестов) возвращает товар на склад и сохраняет копию в архиве.

**Финансы** (управленческий учёт, не заменяет бухгалтерию и налоговую отчётность)
- Выручка — по дате оплаты; неоплаченные заказы отдельно.
- Себестоимость — по закупочной цене **на момент продажи**; валовая прибыль = выручка − себестоимость; чистая прибыль = валовая − расходы магазина + прочие доходы.
- Закупка товара — движение денег, но не расход для прибыли (учитывается через себестоимость). Вложения владельца и возвраты от поставщика — не прибыль.
- Отчёты: сегодня, эта неделя, 7 дней, месяц, квартал, год, любой период; вкладки «Касса», «Прибыль», «Продажи по дням», «Расходы», «Журнал»; выгрузка в Excel.

**Админка**: главный экран «что сделать сейчас», быстрые действия, понятные пустые разделы, подтверждение всех опасных действий, кнопки на телефоне больше не уходят за край экрана, убран «Сброс к демо-данным».

**Бренд** (для другого магазина): название, короткое название, слоган, логотип, акцентный и тёмный цвета, город, часы работы, WhatsApp, Facebook, TikTok, YouTube, карта — Админ → Настройки → Бренд магазина. Подставляется на сайт, в письма и SMS.

**Безопасность**: в Production пароль `admin` не работает; без `ADMIN_PASSWORD`/`SESSION_SECRET` вход отключён; смена пароля и «выйти на всех устройствах» закрывают сессии; ограничение попыток входа, заказов, промокодов и подписок; все 17 административных API без входа → 401; закупочные цены, хеш пароля, пароли SMTP и токены не уходят в браузер; проверка загружаемых файлов по содержимому; защита от CSV-инъекций.

**Исправлены ошибки**: 97 искажённых букв на витрине; тексты главного баннера из админки не показывались на сайте; срок возврата «14 дней» был зашит и расходился с настройкой; «Более 50 моделей» на пустом каталоге; пустые блоки на главной; кнопки админки на телефоне; уведомления о заказах не отправлялись.

## Шаги запуска

1. **Хостинг.** Vercel разрешает тариф Hobby только для некоммерческого использования — магазину нужен **Vercel Pro** (решение и оплата — за владельцем). Turso Free (5 ГБ, 500 млн чтений/мес) хватит с запасом.
2. **Резервная копия текущего сайта**: Админ → Настройки → Скачать резервную копию (в GitHub не класть).
3. **Проверка чистого запуска** (ничего не записывает):
   `vercel env pull .env.production.local --environment=production`
   `node scripts/migrate-to-turso.js --clean --source <файл копии>`
4. **Согласование и запуск переноса**: `node scripts/migrate-to-turso.js --clean --source <файл> --apply`. Переносятся настройки, категории, цвета, размеры, бренд, контакты, промокоды; товары, заказы, подписчики и финансы уходят в архив (`quarantine`). Демо-акция выключается.
5. **Проверка превью PR #1** (в Preview используется временная база с демо-данными).
6. **Объединение PR с main** → Vercel публикует сайт. Проверить `/api/health` → `{"ok":true,"storage":"turso"}`.
7. **Первый вход**: пароль из `ADMIN_PASSWORD`, сразу сменить в Настройках. Заполнить «Бренд магазина» и контакты.
8. **Боевая проверка**: добавить 1 товар → заказ с телефона → отметить оплату → отмена → проверить остаток и отчёт → удалить тестовый заказ и товар (копии останутся в архиве).

Откат: Vercel → Deployments → предыдущий деплой → Promote to Production. Данные в Turso при этом не теряются.

## Обслуживание

- Резервная копия: кнопка в админке или `node scripts/db-export.js` (раз в неделю). Turso Free хранит точку восстановления только за 1 день.
- Забыли пароль: `node scripts/reset-admin-password.js`.
- Регион базы Turso должен быть рядом с регионом функций Vercel (по умолчанию `iad1`).

## Платформа для другого магазина

Каждый магазин — отдельная копия: свой репозиторий (fork), свой проект Vercel, своя база Turso, свои `ADMIN_PASSWORD` и `SESSION_SECRET`. Данные магазинов никогда не смешиваются. После `--clean` переноса настроек владелец заполняет «Бренд магазина», категории, цвета, размеры, доставку и оплату в админке.
